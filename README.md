# Get_xyz_for_metal_complexes
Jupyter notebook to generate .xyz files for metal complexes from smiles. 

This script uses molSimplify (from the Kulik group at MIT) to obtain 3D structure of the metal complexes.

The generated .xyz files are then used as an input for geometry optimization, followed by xTB/DFT optimizations.
